# Ajit Sinh Rajput Portfolio

Personal software engineering portfolio built with React, TypeScript, and Vite.

## Tech Stack

- React 18
- TypeScript
- Vite
- Formspree contact form
- Ant Design theme switch
- Typed.js hero text
- GitHub Pages deployment

## Local Development

```bash
npm install
npm run dev
```

The app runs locally with the GitHub Pages base path:

```text
http://localhost:5173/Ajit-Portfolio/
```

If that port is busy, Vite will choose the next available port.

## Quality Checks

Run these before deploying:

```bash
npm run lint
npm run build
```

## Deployment

This project deploys to GitHub Pages from the generated `dist` folder using the `gh-pages` package.

Full instructions are in [DEPLOYMENT.md](./DEPLOYMENT.md).
